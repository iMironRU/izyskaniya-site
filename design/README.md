# Дизайн

`handoff/` — хендофф дизайнера (направление «Отчёт», рабочее название «ГЕОПЛАН»), распакован из архива «Форма обратной связи.zip» 30.09.2026 без изменений.

- `handoff/README.md` — обзор, раскладка, взаимодействия, открытые вопросы;
- `handoff/tokens/` — DTCG-токены (источник для `tokens/` в корне);
- `handoff/components/*.md` — анатомия 43 компонентов;
- `handoff/pages/*.md` — контракты 25 страниц;
- `handoff/prototype/` — HTML-прототипы (референс, не продакшен-код), открывать `Сайт - прототип.dc.html`;
- `handoff/screenshots/` — первые экраны страниц.

Истина в проекте — код и `tokens/` в корне. Эта папка — входные данные от дизайна: при новой версии хендоффа кладём её сюда целиком и переносим изменения в код.
