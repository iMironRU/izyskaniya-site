# Калькулятор

**URL:** `/raschet`  
**Прототип:** `Прототип - Частный дом.dc.html`

## Блоки по порядку

| № | Блок | Компоненты |
|---|---|---|
| 1 | Шаги: Что строите → Этажность (пропускается для бани) → Габариты → Фундамент → Участок (кадастр/карта/пропустить) → Топосъёмка | calc-progress, calc-step, option-tile, input |
| 2 | Результат частного объекта | calc-result, borehole-scheme, assumption-badge, norm-link |
| 3 | Пакет «геология + топо» −10% | кнопка-предложение в сайдбаре результата |
| 4 | Контакт после результата: телефон, имя, способ связи | callback-form (вариант калькулятора) |
| 5 | Успех / ошибка / нет сети | переключается в Tweaks: sendOutcome |
| 6 | PDF A4 | PDF - Программа работ.dc.html |

## Mobile

- Все сетки — auto-fit/auto-fill, одна колонка на 390px. Таблицы по правилу А/Б/В. Горизонтальной прокрутки нет.
- Один вопрос на экран, Назад/Далее в sticky-bar. На desktop справа сводка «Ваш объект».
