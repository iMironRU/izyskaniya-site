# Хэндофф: сайт инженерно-изыскательской компании (рабочее название «ГЕОПЛАН»)

## Обзор
Сайт компании, которая выполняет инженерные изыскания: 25 шаблонов страниц, калькулятор с предварительной программой работ и макет PDF A4. Визуальное направление — 1a «Отчёт»: страница как хорошо свёрстанный технический отчёт. Цвет используется только в линиях, текст набран антиквой, цифры табличные, нормативы оформлены штампом.

## О файлах дизайна
Файлы в `prototype/` — **дизайн-референсы в HTML**: прототипы показывают, как интерфейс выглядит и ведёт себя. Это не продакшен-код. Задача — воспроизвести их на зафиксированном стеке (React + Tailwind, DTCG-токены → Style Dictionary v4 → CSS-переменные и Tailwind-пресет, Storybook, Onlook, Playwright) по его правилам.

**Источник истины** — токены в `tokens/`, анатомия в `components/*.md` и контракты страниц в `pages/*.md`. Прототип нужен, чтобы посмотреть и проверить поведение.

## Точность
**High-fidelity.** Цвета, шрифты, шкалы, состояния и адаптив финальные. Демо — только тексты, цифры, реквизиты и изображения: всё помечено как заглушка, реальный контент передаёт заказчик.

## Как открыть прототип
Откройте `prototype/Сайт - прототип.dc.html`. В нём desktop (1280) и mobile (390) идут рядом и синхронизированы: переход и прокрутка в одном кадре повторяются в другом. Сверху расположены чипы всех страниц. Калькулятор — `prototype/Прототип - Частный дом.dc.html`, у него свои синхронные кадры и Tweaks для исхода отправки. PDF — `prototype/PDF - Программа работ.dc.html`.

## Экраны
Полный список с порядком блоков и слотами — в `pages/`. Коротко:
- Главная, Услуги, Направление (шаблон), Услуга (шаблон, полный и минимальный), Цены, Калькулятор + результат + PDF;
- Частным, Проектировщикам (форма ТЗ с загрузкой), Образцы + просмотрщик, Объекты (карта/список) + Кейс;
- О компании (паспорт), Команда, Лаборатория, Техника, Документы (копирование реквизитов);
- Как работаем, Проверка подрядчика (лонгрид), Вопросы (поиск + разделы), Статьи + Статья, Контакты;
- 404, Спасибо, Политика.

Шаблонные страницы описаны данными в `prototype/pages-data.js`. Одинаковая схема блоков `{type, …}` подходит и как контракт для CMS.

## Раскладка
- Mobile-first. Точка перелома одна — `768px` (`breakpoint.md`). Ниже неё шапка mobile, бургер и sticky-bar.
- Поля страницы: `clamp(20px, 4.4vw, 56px)`. Расстояние между секциями: `clamp(40px, 5.5vw, 72px)`.
- Сетки только `auto-fit/auto-fill minmax(min(100%, Npx), 1fr)`: одна колонка на 390, две–четыре на 1280.
- Кегли заголовков через clamp: H1 34 → 54, H2 26 → 40.
- Зоны нажатия не меньше 44px, кнопки на мобильном 48px.
- **Таблицы на телефоне без горизонтальной прокрутки** (правило в `components/table.md`):
  - А — справочная таблица превращается в карточки;
  - Б — матрица: одно измерение выбирается переключателем;
  - В — длинная таблица: первые 5 строк и кнопка «Показать все».

## Взаимодействия
- Состояния всех интерактивных элементов: hover — тинт 12% gold или 7% ink; active — 22%; фокус — `outline: 2px solid gold; offset 2px`; disabled — opacity 0.45.
- Калькулятор:
  - вариант «Не знаю» у каждого шага;
  - валидация по «Далее»;
  - Enter переходит к следующему шагу;
  - шаг «этажность» пропускается для бани и гаража;
  - контакт спрашиваем только после результата;
  - «Уточнить» у допущения возвращает на нужный шаг.
- Правила расчёта в прототипе демонстрационные (`calc()` в файле калькулятора). Настоящую модель передаёт заказчик данными.
- Формы:
  - маска телефона `+7 (XXX) XXX-XX-XX`;
  - кадастровый номер `NN:NN:NNNNNN(N):N…`;
  - файл ТЗ до 25 МБ;
  - состояния: отправка → успех / ошибка / нет сети.
- Попапов нет. Меню, панель «Услуги» и просмотрщик открываются только по действию пользователя и закрываются по Esc. В просмотрщике работают стрелки ← →.
- Анимаций нет, кроме плавной прокрутки к разделу (отступ 80px под шапку).

## Состояние
- Калькулятор: `screen`, `step`, `ans{obj, floors, dims, found, loc, topo}`, `L`, `W`, `cad`, `pt`, `phone`, `name`, `via`, `send`.
- Страницы: открытый пункт FAQ, фильтр, поиск, режим «карта/список», выбранная точка, просмотрщик `{items, idx}`, `zoom`.

## Токены
`tokens/primitive.json`, `tokens/semantic.json`, `tokens/component.json` — формат DTCG, ссылки вида `{color.accent.700}`. Конфиг сборки — `tokens/style-dictionary.config.mjs`.

Ключевые значения:
- **Фон** `#f3f2f2`; **поверхность** `#eae9e9`; **текст** `#201f1d`.
- **Акцент** `#b68235` — только линии, иконки и крупный текст. Мелкий акцентный текст — `#7d5411` / `#5a3b0a`.
- **Линии** `rgba(32,31,29,.16)`.
- **Шрифты:** Cormorant Garamond 400/600 (заголовки, цифры) и Lora 400/600 (текст). Оба с кириллицей, лицензия OFL.
- **Цифры:** `font-variant-numeric: tabular-nums` для всех чисел вне сплошного текста.
- **Отступы** (плотность 1.15): 4.6 / 9.2 / 13.8 / 18.4 / 27.6 / 36.8. **Радиусы** 2 / 4 / 7.
- **Тени** sm / md / lg — «шёпотом».
- Цветовая схема моно, поэтому ошибка передаётся не красным цветом, а рамкой gold, текстом `#5a3b0a` и формулировкой.

## Иконки и изображения
- Иконки — Lucide, линейные, 1.5px, `currentColor`.
- Схема скважин, колонка, разрез и паттерны сделаны в SVG.
- Все фото и сканы пока заглушки: `.plate` со штриховкой 45° и подписью «Заглушка · что здесь будет».

## Открытые вопросы (решены по умолчанию, подтвердить)
- **Бренд** — нейтральный шаблон, бренд подставляется токенами (12.1в). «ГЕОПЛАН» — заглушка.
- **Тема** — только светлая.
- **Изображения** — смешанный вариант.
- **Статьи** — шаблон заложен.
- **SEO-посадочные по городам** — не делаем.
- **Сценарные страницы** — две отдельные.
- **Гарантии** (снятие замечаний без доплат, неустойка) — подтверждает заказчик.

## Файлы
- `tokens/` — DTCG, 3 слоя, и конфиг Style Dictionary.
- `components/*.md` — 43 компонента: части, варианты, состояния, слоты, поведение, токены.
- `pages/*.md` — 25 контрактов страниц.
- `prototype/` — HTML-прототипы. Открывать из этой папки: пути к `_ds/` относительные.
- `screenshots/` — первые экраны всех страниц (около 900px) и скрипт Playwright `capture.mjs`, который снимает страницы на 1280 и 390 во всю высоту.

Примечание: шапка переключается на мобильную ниже 1080px (раньше общей точки 768px), чтобы меню и телефон не переносились на планшетах.
