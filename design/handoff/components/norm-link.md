# norm-link

Ссылка-норматив — узнаваемый «штамп».

## Части
- ячейка типа (СП/ГОСТ)
- ячейка номера

## Варианты
- inline
- в таблице
- мобильный 11px

## Состояния
- default
- hover — рамка gold (если ссылка)
- focus-visible

## Слоты / props
- type
- code
- href

## Поведение
- Рамка ink 1px, radius 2px, tabular-nums, разделитель между ячейками

## Токены
component.norm-stamp.*
