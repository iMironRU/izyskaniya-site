# Скриншоты

- `tablet-900/` — первый экран каждой страницы при ширине около 900px, снято в среде прототипа. На этой ширине шапка уже мобильная (переход на 1080px), сетки в две-три колонки.
- `capture.mjs` — скрипт Playwright. Снимает все 26 страниц на 1280 и 390 px во всю высоту в `desktop-1280/` и `mobile-390/`. Эти снимки и станут эталонами для визуальной регрессии.
