# cards

Карточки (общая анатомия .card).

## Части
- plate-превью (опц.)
- кикер
- заголовок
- описание
- факты-теги
- мета/цифра под линией

## Варианты
- направление
- услуга
- сценарий (строка оглавления)
- образец отчёта (3:4, открывает viewer)
- кейс (цифра)
- человек (4:5)
- техника
- документ (+скачать)
- статья (обложка, время чтения)
- логотип партнёра

## Состояния
- default
- hover — рамка gold
- focus-visible
- dimmed при фильтре 0.5

## Слоты / props
- по варианту

## Поведение
- Сетка auto-fill minmax(min(100%,Npx),1fr)

## Токены
component.card.*, component.plate.*
