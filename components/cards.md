# Карточки

`src/components/Card/`

Общее: белый фон `card.bg`, рамка `card.border`, без теней; вся карточка — одна ссылка (заголовок — ссылка, растянутая на карточку); hover — рамка `card.border-hover`; focus — контур вокруг карточки.

**ServiceCard — услуга.** Иконка 24 px цвета акцента, заголовок 18 px, описание 2–3 строки, цена «от …» (`PriceTag kind="from"`), стрелка.

**SampleCard — образец отчёта.** Превью (соотношение 3:4, пока — штриховка-заглушка с подписью «Превью появится»), бейдж типа («Разрез», «Колонка скважины», «Протокол», «Заключение»), заголовок, мета-строка (объект, год).

**CaseCard — кейс.** Заголовок объекта, место, 2–4 цифры кейса парами «значение — подпись» (моноширинные значения), ссылка «Подробнее».

**Изображения:** реальных фото пока нет — заглушки явно подписаны, стоки не используем.
