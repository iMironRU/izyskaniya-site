# Анатомия компонентов

Черновик набросан разработчиком по направлению A «Технический отчёт» (канвас: https://claude.ai/artifact/JsFFPFjcMW8dZGtMRvwZUm). Дизайнер правит визуал через Onlook прямо в коде компонентов и через токены; эти файлы описывают договорённость: части, варианты, состояния, поведение.

Общие правила для всех компонентов:
- Mobile-first: стили без префикса — телефон, `md:` и выше — планшет и десктоп.
- Зона нажатия не меньше 44 × 44 px (`space.11`).
- Фокус с клавиатуры виден всегда: контур 3 px цвета `color.focus.ring` (общий стиль в `globals.css`).
- Контраст текста не ниже 4.5:1, границ полей и индикаторов — не ниже 3:1.
- Иконки — один линейный набор (lucide), толщина линии 1.75, без эмодзи.
- Цвета, размеры и отступы — только из токенов. Своё значение → сначала токен.
- Числа табличные (`tabular-nums`), коды нормативов — моноширинным шрифтом (`font.family.code`).
