# table

Таблица и правило для телефона.

## Части
- thead UPPERCASE 11px
- строки с линиями

## Варианты
- А. справочная (≤4 кол.) → на телефоне карточки: 1-я колонка заголовок, остальное пары
- Б. матрица → переключатель одного измерения + список
- В. длинная (>6 строк) → 5 строк + «Показать все»

## Состояния
- hover строки 4% ink

## Слоты / props
- cols
- rows

## Поведение
- Горизонтальной прокрутки нет нигде
- Числа — tabular, выравнивание вправо

## Токены
component.table.*
