# StickyActionBar — липкая панель на телефоне

`src/components/StickyActionBar/`

**Части:** две кнопки: «Позвонить» (`secondary`, 1/3 ширины) и главное действие (`primary`, 2/3, по умолчанию «Рассчитать программу» — в одну строку на телефоне 360 px). Фон страницы, верхняя линия, отступ снизу под «домашнюю полоску» iPhone (`safe-area-inset-bottom`).

**Поведение:** закреплена внизу экрана только на телефоне (< `md`), на больших экранах скрыта. На странице калькулятора не показывается (там своя кнопка «Дальше»). Под панелью у страницы есть запас снизу, чтобы она не закрывала контент.
