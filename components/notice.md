# Notice — уведомление

`src/components/Notice/`

**Тона (`tone`):**
- `success` — заявка отправлена;
- `error` — ошибка отправки (с кнопкой «Повторить»);
- `offline` — нет сети (форма сохранена, отправим, когда появится связь);
- `info` — нейтральное сообщение (например, «цены обновились с момента расчёта»).

**Части:** иконка тона, заголовок 16 px, текст 15 px, необязательное действие (кнопка `text` или `secondary`). Фон — `status.*-subtle` / `bg.subtle`, рамка слева не используется — рамка по всему контуру цвета тона.

**Доступность:** `role="status"` для success/info/offline, `role="alert"` для error. Не всплывающее окно: уведомление встаёт на место формы.
