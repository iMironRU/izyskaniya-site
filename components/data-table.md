# DataTable и PriceMatrix — таблицы

`src/components/DataTable/`

**DataTable — обычная таблица** («этап → работы → норматив», таблица работ в результате).
- Части: подпись (`caption`), шапка на фоне `table.head-bg`, строки с линией `table.rule`, итоговая строка с верхней линией `table.rule-strong`.
- Колонки описываются массивом: заголовок, выравнивание (`align: 'end'` для чисел), признак «главная колонка».
- **На телефоне** (< `md`) каждая строка превращается в карточку: главная колонка — заголовок карточки, остальные — пары «подпись — значение». Шапка таблицы скрыта, но таблица остаётся таблицей для скринридера.

**PriceMatrix — матрица цен** («пятно застройки × этажность»).
- Части: подпись и строка «Строки — …, столбцы — …», угловая ячейка с названием оси строк, заголовки строк и колонок, ячейки-цены (`PriceTag`).
- **На телефоне:** первая колонка закреплена (`sticky`), остальные прокручиваются вбок; под подписью — подсказка «Таблица прокручивается вбок». Прокручиваемая область фокусируется с клавиатуры (`tabIndex=0`, `role="region"` с подписью).
- Цены в ячейках считаются движком (`priceMatrix`).
