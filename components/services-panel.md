# services-panel

Выпадающая панель направлений (не мега-меню).

## Части
- 7 колонок-направлений
- 3 главные услуги
- цена «от»
- ссылка «Все услуги»

## Варианты
- desktop only

## Состояния
- open/closed
- hover пункта accent-800

## Слоты / props
- directions[]

## Поведение
- Сетка auto-fill minmax(220px)
- Закрытие: Esc, клик по пункту
