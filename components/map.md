# map

Карта объектов (заглушка).

## Части
- фильтры
- точки
- карточка выбранной точки
- список

## Варианты
- desktop: карта + список
- mobile: переключатель Список/Карта, по умолчанию список

## Состояния
- точка выбрана (26px, заливка gold)

## Слоты / props
- items[]

## Поведение
- Кластеризация — в реальной карте
