# QuizProgress — прогресс калькулятора

`src/components/QuizProgress/`

**Части:** строка сверху — название раздела слева («Геология»), счётчик «3 из 7» справа моноширинным шрифтом; ниже полоса из N сегментов высотой 4 px с зазором 4 px.

**Сегменты:** пройденные — `progress.done` (графит), текущий — `progress.current` (охра), будущие — `progress.track`.

**Доступность:** `role="progressbar"` с `aria-valuemin/max/now` и `aria-valuetext` («Вопрос 3 из 7»).

**Поведение:** число шагов меняется, если ответ открывает или скрывает вопросы, — полоса пересчитывается без анимации скачков.
