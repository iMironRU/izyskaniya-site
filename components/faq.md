# Faq — аккордеон

`src/components/Faq/`

**Части:** список вопросов; вопрос — строка 16 px полужирная с иконкой «+», ответ — текст 15 px.

**Поведение:** нативные `details/summary`: работает без JavaScript, с клавиатуры (Enter/Пробел), открытые пункты независимы. Открытый пункт — иконка поворачивается в «×».

**SEO:** данные те же, что для разметки schema.org `FAQPage` (генерируется из того же массива).
