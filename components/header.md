# header

Шапка сайта (desktop + mobile).

## Части
- логотип
- меню: Услуги▾, Цены, Образцы, Объекты, О компании, Контакты
- телефон + график
- кнопка «Рассчитать стоимость»
- mobile: логотип, телефон-иконка, бургер

## Варианты
- desktop ≥768
- mobile <768

## Состояния
- sticky
- пункт текущей страницы — aria-current, accent-800
- панель «Услуги» открыта

## Слоты / props
- current

## Поведение
- «Услуги» открывает services-panel по клику; Esc закрывает
- Бургер открывает mobile-menu

## Токены
component.header.*
